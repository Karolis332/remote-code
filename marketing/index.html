01 · Premise
01

Coding agents are 24/7 workers stuck inside an 8-hour-a-day human at a desk. When you close the laptop, the fleet stops. When you sit down with a coffee, you spend twenty minutes remembering what you were doing.

RemoteCode unbinds that. A daemon runs on your computer. A Telegram chat in your pocket talks to it. Agents you've spawned keep their cwd, their history, and their patience. When their rate limit hits, they wait politely and resume on their own. When something breaks, the Foreman reports it before you have to ask.

You bring your own Claude account. We bring the office, the dispatch desk, the manager that never sleeps, and the only door you need — your phone.

02 · How

Three steps. No cloud. No keys leaving the machine.

Telegram is the relay. Your PC is the runtime. Your Claude account stays where you put it. Zero infrastructure between them.

Step 01 · install

Boot the daemon

One command. RemoteCode auto-detects your `claude` CLI, registers as a system service (systemd / launchd / Windows service), and prints a pairing code. 

$ curl -fsSL remotecode.io/get | sh
› claude detected ✓ (Claude Code v0.18.2)
› systemd unit installed
› pairing code: H7Q-4F2
Step 02 · pair

Pair your phone

Open Telegram, message your RemoteCode bot, send the code. Your chat ID gets whitelisted. Nobody else can drive the daemon. 

@you → /pair H7Q-4F2
@bot ← paired · chat #2847219
@bot ← 0 agents yet · /new to spawn
Step 03 · dispatch

Run the fleet

Spawn agents. Each gets its own working directory, history, and quota slice. Drive them by text or voice note. The Foreman watches them all. 

@you → /new druka ~/druka
@you → /run druka "fix the failing rspec"
@bot ← ✓ tests pass · 3 files touched
@bot ← ready

Telegram is the bus. Your computer is the office.

Zero hosted infrastructure. Zero cloud relay. The Bot API is the only long-haul protocol. Your daemon long-polls. Every byte stays on your machine.

BYOK · your Anthropic account · no key plumbing

// daemon

Long-running Node process. SQLite-backed state survives a kill -9. Each worker is a `claude` subprocess in its own working directory. Crashes are isolated; the bot stays up.

// quota tracker

Parses CLI output for the exact rate-limit message Anthropic emits. Agents auto-pause until reset. The bot tells you when, and again when they resume. No "your agent stopped" mystery.

// the foreman

One always-on supervisor agent runs in the background. Ticks every 60s, reviews hourly, digests daily, summarizes weekly. Cannot be killed — only paused. Reports straight to your chat.

// transport

Telegram's Bot API is the relay. No cloud server, no NAT punching, no account RemoteCode controls. The daemon long-polls; messages flow both ways through Telegram's encrypted transport.

04 · The Foreman

The supervisor that never punches out.

Every RemoteCode instance ships with one always-on agent — the Foreman. They watch the fleet, review the work, surface what matters, and stay out of the way. These are their laws.

L01Never modify a worker's code without explicit authorization.
L02Report any worker stuck more than thirty minutes without progress.
L03Flag uncommitted changes older than two hours.
L04Send the operator a daily digest at 18:00 EET by default.
L05A Telegram message is never longer than four pages in one report.
L06Cannot be killed by /kill. May be paused. Reboots with the daemon.
L07Logs every action to data/supervisor.log with timestamps.
L08Never reveals secrets or credentials even when asked.
L09Light review hourly. Full review daily. Portfolio summary Sundays 09:00.

06 · Specs

The fine print, spoken plainly.

Do I need an API key from Anthropic?
No. RemoteCode never touches your API key. It uses the claude CLI that's already authenticated against your Pro / Max / API subscription. We can't see, store, or proxy your credentials — that's the privacy moat.
What happens when my Claude session limit hits?
The daemon parses the rate-limit message the CLI emits, marks the agent as paused, pings you on Telegram with the reset time, and wakes the agent up when the window opens again. No babysitting required.
Can I run multiple agents on different projects?
That's the entire premise. Each agent has its own name, working directory, history, and quota slice. /new druka ~/projA, /new ecmr ~/projB, and they run in parallel. The Foreman watches all of them.
Does it work behind NAT / on residential internet?
Yes. The daemon long-polls Telegram's Bot API outbound — there are no inbound ports to open. Works behind home routers, ISP CGNAT, corporate firewalls, hotel WiFi.
Voice messages?
Send a Telegram voice note. The daemon transcribes it with OpenAI Whisper (if you've set OPENAI_API_KEY) or local whisper.cpp otherwise. The transcript becomes a /run to the default agent.
Does my PC need to stay on?
For agents to work, yes — but that's a feature. RemoteCode is for people who keep their machine running and want it to actually do something while they're not at it. SQLite-WAL means a crash or power blip doesn't lose state. systemd / launchd / Windows-service registration means it restarts automatically.
Where's the source?
github.com/Karolis332/remote-code · open-core. The daemon is MIT. Paid features (multi-PC, agency tier) live in a closed plugin.
